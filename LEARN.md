# LEARN.md

## Что сделали
Разработали API-сервис с одинаковым функционалом (CRUD для списка задач), реализованным на Flask и FastAPI. Проект позволяет сравнить синхронный подход Flask и асинхронный FastAPI на практике, измерить производительность и удобство написания кода.

## Что разобрать
1. Синхронная архитектура Flask.
2. Асинхронная архитектура FastAPI.
3. Использование Uvicorn для запуска FastAPI.
4. Общие модели данных (`models.py`) для обеих реализаций.
5. Написание тестов для Flask и FastAPI.
